## Reading and text-extraction notes

I read The Foundations of Business, including its discussion of businesses, customers and stakeholders, and compared the PDF layout with extracted text.

- PDF page 2 places a figure and its caption beside the opening text. The extracted caption appears before the chapter heading, so reading order needs checking.
- PDF page 3 contains raised reference numbers within paragraphs and a repeated footer. Those numbers and footer text should not become part of a question.
- The copyright page contains a line break inside a word in the extracted text. Cleaning must avoid changing the meaning of words.
- Printed page numbers differ from PDF positions: PDF page 3 is printed page 21. Source links will use PDF positions and show the file name.
- Diagrams, pictures and reference lists are not suitable question evidence for the first text-only version. Use the explanatory paragraphs and preserve their page references.

Think Python also contains code, symbols and glossary sections. Code spacing must be preserved, and questions needing code execution are outside the first version.
